
# Task Manager

## О проекте

Task Manager — учебное приложение на Python для управления списком задач.

Проект разработан для изучения Git, GitHub Actions
и процессов непрерывной интеграции и доставки (CI/CD).

## Возможности

- Добавление задач.
- Просмотр списка задач.
- Отметка задач как выполненных.
- Удаление задач.
- Поиск задач по названию.
- Проверка корректности индексов.

## Пример использования

```python
from task_manager import TaskManager

manager = TaskManager()

manager.add_task("Изучить GitHub Actions")
manager.add_task("Написать тесты")

manager.complete_task(0)

print(manager.get_tasks())
```

## Тестирование

Для проверки функциональности используется pytest.

Запуск тестов:

```bash
python3 -m pytest tests/ -v
```

## CI/CD

В проекте используется GitHub Actions.

При обновлении кода автоматически выполняются:

1. Проверка проекта модульными тестами.
2. Сборка документации.
3. Публикация документации при обновлении main.
